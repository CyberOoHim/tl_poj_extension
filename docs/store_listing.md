# Chrome Web Store Listing / Chrome 線上應用程式商店內容

## Name / 名稱

TL -> POJ 隨時轉 (Suî-sî-tsuán)

## Summary / 摘要 (Max 132 chars)

**English:** Instant Tâi-lô (TL) to POJ converter for web pages, typing, and files. Privacy-focused, runs 100% locally.

**Taigi:** 隨時 kā 網頁、拍字、文件 ê 台羅 (TL) 轉做白話字 (POJ)。lóng-chóng tī 你的電腦運作，保證隱私。

## Detailed Description / 詳細說明

**TL -> POJ Suî-sî-tsuán** is a browser tool designed for Taiwanese language users. It allows you to instantly convert **KIP Tâi-lô (TL)** to **Pe̍h-ōe-jī (POJ)** across web pages, text input, and various file formats.

**TL -> POJ 隨時轉** 是一款專門為台語使用者設計 ê Chrome Extension。伊 hō͘ 你 tī 網頁、拍字、抑是各種檔案格式，隨時 kā **教育部台羅拼音 (KIP Tâi-lô)** 轉做 **白話字 (Pe̍h-ōe-jī)**。

### Core Features / 主要功能

#### 1. Scan Mode / 轉網頁

* **Select & Convert:** Highlight text on any webpage to see it converted to POJ immediately in the side panel.

    **揀選轉換：** 揀網頁頂懸 ê 文字，隨時 tī 邊欄 kā 轉做 POJ。

* **Live Conversion:** Toggle "Live Mode" to transform the entire webpage's Tâi-lô text into POJ in-place.

    **就地轉 (Live Conversion)：** 直接原位 kā 規頁網頁 ê TL 轉做 POJ，原位顯示。

* **Markdown Support:** Copy converted content as Markdown, preserving links and formatting.

    **Markdown 支援：** 會使 kā 轉好 ê 內容 Kho͘ (Copy) 做 Markdown，保留網鏈 kah 格式。

#### 2. Type Mode / 拍字轉

* **Real-time Editor:** Type Tâi-lô with numeric tones (e.g., `tsui2`) or diacritics (e.g., ) and see POJ output（chúi） instantly.

    **即時編輯器：** 輸入 Tâi-lô 數字調`tsuí` (像 `tsui2`) ah-si 符號調號 (像 `tsuí`)，隨 tō 看著 POJ 輸出（chúi）。

* **Inject:** Directly paste converted POJ into active text fields on websites.

    **Pôaⁿ (Inject)：** 直接 kā 轉好 ê POJ 貼入去網頁 ê 輸入框。

#### 3. File Mode / 轉書類

* **Multi-format Support:** Convert `.txt`, `.md`, `.srt` (Subtitles), `.csv`, `.json`, and `.pdf` files efficiently.

    **濟格式支援：** 支援轉換 `.txt`, `.md`, `.srt` (字幕), `.csv`, `.json`, kah `.pdf` 檔案。

* **Advanced Options:** Customize which columns (CSV) or keys (JSON) to convert. For subtitles, choose specific lines to convert for bilingual display.

    **進階設定：** 會使揀欲轉 CSV ê 直逝 (columns) 抑是 JSON ê Key。字幕嘛會使揀欲轉第幾逝，方便做雙語字幕。

#### 4. Customization / 設定

* **Nasal Tone:** Choose whether to use `N`. `nn` is always converted (superscript n).

    **鼻化音：** 選擇 kám 欲用 `N` 。 `nn` 是一定會轉 (superscript n)。

* **Tone 6:** Choose between `á` (acute) or `ǎ` (caron).

    **第 6 調：** 選擇欲用 `á` (acute) 抑是 `ǎ` (caron)。

* **Dark Mode:** A comfortable dark theme for scanning and reading.

    **暗暝模式：** 規个暗色，hō͘ 目睭較四序。

### Privacy Policy / 隱私權政策

**We respect your privacy.**

**阮尊重你 ê 隱私。**

* **No Remote Servers:** We do not collect, store, or transmit your personal data.

    **無遠兜主機：** 阮無收集、無 khiām、mā 無傳送你 ê 任何個人資料。

* **Local Processing:** All conversions (Web Scanning, Typing, File Conversion) happen entirely within your browser using JavaScript.

    **在地處理：** 所有的轉文字功能 (轉網頁、拍字轉、轉書顃) lóng 是直接 tī 你 ê 瀏覽器 (Browser) 內底運作。
